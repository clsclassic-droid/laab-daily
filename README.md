## ทำอะไรได้บ้าง (v17)

เมนูด้านบนมี: **บันทึกประจำวัน** · **แดชบอร์ด** · **เจ้าหนี้** (และปุ่มเลื่อนวัน ‹ › / เลือกวันที่ / วันที่บันทึกไว้)

**หน้าบันทึกรายวัน**
- รับเงิน 4 ช่องทาง: เงินสด · โอน · Grab (หักค่าคอมอัตโนมัติ ลงยอดเต็ม) · ไทยช่วยไทย
- ซื้อของ **18 หมวด 4 กลุ่ม** (วัตถุดิบอาหาร · เครื่องดื่ม/น้ำแข็ง · บรรจุภัณฑ์/ของใช้สิ้นเปลือง · ค่าใช้จ่ายดำเนินงาน) ดูรายละเอียดหมวดในหัวข้อผังบัญชีด้านล่าง
- ช่อง `จำนวน × ราคา = ยอดรวม` กรอกช่องไหนก่อนก็ได้ ระบบเติมช่องที่เหลือให้
- วิธีจ่ายผูกกับ "ร้าน": สด · โอน · เชื่อ · ค้างจ่ายร้านก๋วยเตี๋ยว
- เช็คชื่อพนักงานรายวัน (ค่าแรง) และบันทึกเบิกเงินล่วงหน้า
- นับเงินปลายวัน เทียบกับที่ควรมี เตือนเงินขาด/เงินเกิน เงินสดจากเมื่อวานยกมาอัตโนมัติ
- เงินสดที่จ่ายชำระเจ้าหนี้ในวันนั้น หักจากลิ้นชักให้อัตโนมัติ
- ปุ่ม "ปิดยอดวันนี้" บันทึกสมุดรายวันลงฐานข้อมูลจริง (`journal_entries` / `journal_lines`)
- ปุ่ม "เลิกทำ" หลังลบข้อมูลทั้งวัน · คัดลอกสรุปทั้งวันเป็น TSV วางลง Excel · ดาวน์โหลด/นำเข้าสำรอง `.json`

**ตรวจจับความผิดพลาด**
- ราคาต่างจากครั้งก่อนเกิน 10% → เตือน
- ใส่จำนวนแต่ลืมราคา → แถวขึ้นสีส้ม เตือนก่อนปิดยอด
- พิมพ์ครบ 3 ช่องแล้วขัดกัน → ถามว่าเลขไหนถูก ไม่แก้เงียบๆ
- คนอื่นแก้วันเดียวกันพร้อมกัน → ขึ้นแถบให้โหลดใหม่ ไม่เขียนทับที่กำลังพิมพ์

**หน้าเงินเดือน/ค่าแรงรายเดือน** — ปิดยอดรายเดือน ได้ใบ `PR-YYMM` (หักเงินเบิกล่วงหน้าของพนักงานรายเดือน)

**หน้าค่าใช้จ่ายรายเดือน** — 8 บัญชีที่ได้บิลเดียวต่อเดือน (เช่า/ไฟ/น้ำ/POS/เน็ต/ซ่อมบำรุง/สวัสดิการ/การตลาด) กรอกแล้วปิดยอดครั้งเดียว ได้ใบ `ME-YYMM` มีปุ่ม "เปิดแก้ไข" ปลดล็อกแก้ใหม่ และมีช่องระบุว่ามีใบกำกับภาษีหรือไม่ (`has_tax_invoice`)

**หน้าเจ้าหนี้รายร้าน** — ยอดค้าง = ยอดซื้อที่วิธีจ่ายเป็น "เชื่อ" (`2010-LS`) หรือ "ค้างจ่ายร้านก๋วยเตี๋ยว" (`2100-LS`) บันทึกจ่ายชำระได้ ออกใบ `PV-YYMMDD-n` (เดบิตเจ้าหนี้ เครดิตเงินสด `1010` หรือธนาคาร `1020`) ตัดบิลเก่าสุดก่อน

**หน้าสรุปรายเดือน** — ดึงยอดขายและค่าใช้จ่ายจริงจากสมุดรายวัน จัดกลุ่มตาม `cost_group` โชว์ % ต่อยอดขาย, Prime Cost, กำไรจากการดำเนินงาน

**แดชบอร์ด** — แนวโน้มรายเดือน ยอดขาย vs รายจ่าย (กราฟแท่ง/เส้น), Gross Margin, EBITDA, กราฟรายจ่ายรายวันแยกหมวด และ **ประมาณการ VAT รายเดือน** (ประมาณการจากข้อมูลในระบบเท่านั้น ไม่ใช่ตัวเลขยื่นภาษีจริง)

## ใบสำคัญ (เลขที่เอกสาร)

| รูปแบบ | ความหมาย |
|---|---|
| `RJ-YYMMDD-…` | รายการรายวัน (ขาย/ซื้อ/ค่าแรงรายวัน/เบิกล่วงหน้า แยกตามวิธีจ่าย) |
| `PR-YYMM` | ปิดยอดค่าแรงรายเดือน |
| `ME-YYMM` | ปิดยอดค่าใช้จ่ายรายเดือน |
| `PV-YYMMDD-n` | จ่ายชำระเจ้าหนี้ |

(YY = ปี พ.ศ. 2 หลัก สำหรับ `PR`/`ME` ส่วน `RJ`/`PV` ใช้ตามที่โค้ดกำหนด ดูฟังก์ชัน `jeNo`/`prNo`/`meNo`/`pvNo` ในไฟล์โค้ด)

## ผังบัญชีหลักที่ใช้ (สาขา LS)

**หน้ารายวัน — 18 หมวด**

| กลุ่ม | หมวด (รหัส) |
|---|---|
| วัตถุดิบอาหาร | เนื้อ `5010` · ผัก `5020` · เครื่องปรุง/ของแห้ง `5030` · ข้าว/แป้ง `5050` |
| เครื่องดื่ม/น้ำแข็ง | เครื่องดื่ม `5040` · แอลกอฮอล์ `5060` · น้ำแข็ง `5070` |
| บรรจุภัณฑ์/ของใช้สิ้นเปลือง | ถุง/กล่อง `6210` · แก้ว/ชาม `6220` · หลอด/ช้อน `6230` · ทิชชู `6240` · น้ำยาล้างจาน `6250` |
| ค่าใช้จ่ายดำเนินงาน | ค่าแรงคนงาน `6010` · ข้าวพนักงาน `6020` · น้ำมัน/ขนส่ง `6510` · แก๊ส `6140` · เช่าอุปกรณ์/เต็นท์ `6115` · เบ็ดเตล็ด `6900` |

**หน้ารายเดือน — 8 บัญชี:** เช่าร้าน `6110` · ไฟ `6120` · น้ำ `6130` · POS `6310` · เน็ต/โทรศัพท์ `6320` · ซ่อมบำรุง `6410` · สวัสดิการ `6030` · การตลาด `6340`

**บัญชีอื่น:** `1010` เงินสด · `1020` ธนาคาร · `1030` ลูกหนี้ Grab · `1031` ลูกหนี้ไทยช่วยไทย · `1032` ลูกหนี้พนักงาน (เบิกล่วงหน้า) · `2010` เจ้าหนี้การค้า · `2100` เจ้าหนี้ระหว่างกิจการ (ร้านก๋วยเตี๋ยว) · `4010`–`4040` รายได้ · `6330` ค่าคอมมิชชั่นแพลตฟอร์ม

ผังบัญชีเต็มอยู่ในตาราง `accounts` บน Supabase (คอลัมน์ `cost_group` ใช้จัดกลุ่มในหน้าสรุป)

## แก้ไขโค้ด / build

ต้นฉบับ: `laab-daily-entry-v17.jsx` (React) + `entry.jsx` (จุดเริ่ม) + `supabaseClient.js` (ค่าต่อ Supabase)
`index.html` คือไฟล์ที่ build แล้ว ฝัง JS ทั้งหมดไว้ใน `<script>`

```bash
npm install
npm run build        # ได้ app.min.js
# แล้วนำ app.min.js ไปแทนเนื้อหาเดิมทั้งหมดในแท็ก <script> ของ index.html
```

`supabaseClient.js` มี URL และ publishable key ซึ่งฝังฝั่ง client ได้ (ไม่ใช่ secret) สิทธิ์เข้าถึงข้อมูลจริงคุมด้วย Row Level Security ที่ฐานข้อมูล ห้ามฝังคีย์อื่นเพิ่มลงในไฟล์ที่ build แล้ว

หลังแก้และ build เสร็จ ให้บันทึกลง `CHANGELOG.md` ทุกครั้ง
