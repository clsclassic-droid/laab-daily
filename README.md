## ทำอะไรได้บ้าง

**บันทึกรายวัน**
- รับเงิน 4 ช่องทาง: เงินสด · เงินโอน · Grab (หัก % ค่าคอมอัตโนมัติ) · ไทยช่วยไทย
- ซื้อของ 13 หมวด จัดเป็น 3 กลุ่ม ตรงตามผังบัญชี
- ช่อง `จำนวน × ราคา = ยอดรวม` กรอกช่องไหนก่อนก็ได้ ระบบเติมช่องที่เหลือให้

**ตรวจจับความผิดพลาด**
- ราคาต่างจากครั้งก่อนเกิน 10% → เตือน
- ใส่จำนวนแต่ลืมยอดเงิน → แถวขึ้นสีส้ม เตือนก่อนปิดยอด
- พิมพ์ครบ 3 ช่องแล้วตัวเลขขัดกัน → ถามว่าเลขไหนถูก ไม่แก้ให้เงียบๆ
- นับเงินปลายวันไม่ตรงกับที่ควรมี → เตือนเงินขาด/เงินเกิน

**บัญชี**
- แปลงเป็นสมุดรายวันบัญชีคู่สดๆ ข้างจอ ไม่ต้องรู้เดบิต/เครดิต
- แยกใบสำคัญตามวิธีจ่าย: เงินสด · เงินโอน · ซื้อเชื่อ · ค้างจ่ายร้านในเครือ
- เลขที่ใบสำคัญตามวันที่ เช่น `RJ-690602-A`

**ข้อมูล**
- เก็บใน localStorage ของเบราว์เซอร์ ปิดแท็บแล้วเปิดใหม่ข้อมูลยังอยู่
- ราคา "ครั้งก่อน" ดึงจากวันที่บันทึกไว้จริง — ยิ่งใช้ยิ่งแม่น
- เงินสดที่นับได้เมื่อวาน ยกมาเป็นเงินต้นวันอัตโนมัติ
- ย้อนดู/แก้วันเก่าได้
- ดาวน์โหลดสำรองข้อมูล / กู้จากไฟล์ `.json`
- คัดลอกสรุปทั้งวันเป็นตาราง TSV วางลง Excel ได้ทันที

## หลักการออกแบบ

> **อะไรที่ผู้ใช้พิมพ์เอง ระบบห้ามแตะ** — ระบบเขียนทับได้เฉพาะช่องที่ตัวเองเติมให้

ช่องสีเข้ม = พิมพ์เอง · ช่องสีจาง = ระบบคำนวณให้

ตัวอย่าง: ร้านบอกว่าจ่ายไป 5,000 บาท → พิมพ์ยอดรวม 5,000 → ชั่งได้ 10 กก. → พิมพ์ 10
ระบบคำนวณราคาต่อกิโลให้เป็น 500 **โดยไม่แตะยอด 5,000 ที่พิมพ์ไว้**

## ⚠️ ข้อควรรู้เรื่องข้อมูล

**ข้อมูลอยู่ในเบราว์เซอร์ของเครื่องนั้นเครื่องเดียว**

| สถานการณ์ | ผล |
|---|---|
| ปิดแท็บ/ปิดเครื่อง แล้วเปิดใหม่ | ✅ ข้อมูลยังอยู่ |
| เปิดคนละเครื่อง (คอม ↔ มือถือ) | ❌ ไม่เห็นข้อมูลกัน |
| ล้างข้อมูล/แคชเบราว์เซอร์ | ❌ หายหมด |
| เปลี่ยนเบราว์เซอร์ | ❌ ไม่เห็นกัน |

**เลือกเครื่องเดียวเป็นหลัก และกด "ดาวน์โหลดสำรองข้อมูล" อาทิตย์ละครั้ง**

## 🔒 หน้านี้เปิดสาธารณะ — อย่าฝังข้อมูลจริงลงในไฟล์

GitHub Pages บนบัญชีฟรีต้องเป็น repo แบบ public ใครมีลิงก์ก็เปิดดูซอร์สได้

**รายการของ ชื่อร้าน และราคาในไฟล์นี้เป็นข้อมูลตัวอย่าง — ห้ามแก้ให้เป็นของจริง**

ตั้งข้อมูลจริงผ่านหน้าจอแทน (ปุ่ม **"แก้รายการของในหมวดนี้"** ใต้แต่ละหมวด) แก้ชื่อของ หน่วย และร้านประจำได้ ข้อมูลจะเก็บอยู่ในเครื่องของผู้ใช้ ไม่ขึ้นเว็บ

ทำครั้งเดียวจบ แล้วกดดาวน์โหลดสำรองข้อมูลเก็บไว้ ถ้าเปลี่ยนเครื่องก็กู้จากไฟล์นั้น

  --define:process.env.NODE_ENV='"production"' --outfile=app.min.js
