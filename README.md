## ทำอะไรได้บ้าง

**บันทึกรายวัน**
- รับเงิน 4 ช่องทาง: เงินสด · เงินโอน · Grab (หัก % ค่าคอมอัตโนมัติ) · ไทยช่วยไทย
- ซื้อของ 13 หมวด จัดเป็น 3 กลุ่ม ตรงตามผังบัญชี
- ช่อง `จำนวน × ราคา = ยอดรวม` กรอกช่องไหนก่อนก็ได้ ระบบเติมช่องที่เหลือให้

**ตรวจจับความผิดพลาด**
- ราคาต่างจากครั้งก่อนเกิน 10% → เตือน
- ใส่จำนวนแต่ลืมยอดเงิน → แถวขึ้นสีส้ม เตือนก่อนปิดยอด
- พิมพ์ครบ 3 ช่องแล้วตัวเลขขัดกัน → ถามว่าเลขไหนถูก ไม่แก้ให้เงียบๆ
- นับเงินปลายวันไม่ตรงกับที่ควรมี → เตือนเงินขาด/เงินเกิน
- **คนอื่นแก้ไขข้อมูลวันเดียวกันพร้อมกัน** → ขึ้นแถบแจ้งให้กดโหลดใหม่ (ไม่เขียนทับสิ่งที่กำลังพิมพ์อยู่เงียบๆ)

**บัญชี**
- แปลงเป็นสมุดรายวันบัญชีคู่สดๆ ข้างจอ ไม่ต้องรู้เดบิต/เครดิต
- แยกใบสำคัญตามวิธีจ่าย: เงินสด · เงินโอน · ซื้อเชื่อ · ค้างจ่ายร้านในเครือ
- เลขที่ใบสำคัญตามวันที่ เช่น `RJ-690602-A`
- กด "ปิดยอดวันนี้" แล้วสมุดรายวันของวันนั้นจะถูกบันทึกลงฐานข้อมูลจริง (ตาราง `journal_entries`/`journal_lines`) ไม่ใช่แค่คำนวณโชว์เฉยๆ

**ข้อมูล**
- เก็บใน Supabase (ฐานข้อมูลกลาง) — ทุกคนที่ล็อกอินเห็นข้อมูลเดียวกัน ทุกเครื่อง
- ราคา "ครั้งก่อน" ดึงจากวันที่บันทึกไว้จริง — ยิ่งใช้ยิ่งแม่น
- เงินสดที่นับได้เมื่อวาน ยกมาเป็นเงินต้นวันอัตโนมัติ
- ย้อนดู/แก้วันเก่าได้ (ปุ่ม "วันที่บันทึกไว้")
- ดาวน์โหลดสำรองข้อมูล / นำเข้าจากไฟล์ `.json` (รองรับไฟล์สำรองจาก v15 เดิมด้วย นำเข้าแล้วดันขึ้น Supabase ให้อัตโนมัติ)
- คัดลอกสรุปทั้งวันเป็นตาราง TSV วางลง Excel ได้ทันที

## หลักการออกแบบ

> **อะไรที่ผู้ใช้พิมพ์เอง ระบบห้ามแตะ** — ระบบเขียนทับได้เฉพาะช่องที่ตัวเองเติมให้

ช่องสีเข้ม = พิมพ์เอง · ช่องสีจาง = ระบบคำนวณให้

หลักการนี้ขยายไปถึงการซิงค์ข้อมูลหลายเครื่องด้วย: ถ้าคนอื่นแก้ข้อมูลวันเดียวกัน ระบบจะ**แจ้งเตือนให้กดโหลดใหม่เอง** ไม่เขียนทับสิ่งที่กำลังพิมพ์อยู่โดยไม่บอก

## แก้ไขโค้ด

ต้นฉบับคือ `laab-daily-entry-v15.jsx` (React) + `supabaseClient.js` (ค่าต่อ Supabase)
`index.html` คือไฟล์ที่ build แล้ว รวม React + Supabase client ไว้ในตัว

```bash
npm install
npx esbuild entry.jsx --bundle --minify --format=iife \
  --define:process.env.NODE_ENV='"production"' --outfile=app.min.js
# แล้วฝัง app.min.js ลงใน <script> ของ index.html (แทนที่เนื้อหาเดิมทั้งหมดในแท็กนั้น)
```

**ค่าต่อ Supabase** อยู่ใน `supabaseClient.js` — URL และ publishable key ฝังในโค้ดฝั่ง client ได้อย่างปลอดภัย (ไม่ใช่ secret) สิทธิ์เข้าถึงข้อมูลจริงคุมด้วย Row Level Security ที่ฝั่งฐานข้อมูล คนที่ไม่ได้ล็อกอินเข้าไม่ได้
