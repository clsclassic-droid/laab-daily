# ft-build — ชุดสร้างหน้าโรงลูกชิ้น (FT)

- `overlay/` = ไฟล์ที่แก้/เพิ่มจากเว็บดาวเทียมเดิม (`ft-src/`) เพื่อให้ทำงานกับ Supabase
- `build.sh test` → สร้าง `ft-test/` (อ่านอย่างเดียว) · `build.sh live` → สร้าง `ft/` (บันทึกได้)
- ไม่มีข้อมูลลูกค้าหรือยอดจริง (ข้อมูลอยู่ใน Supabase) · คีย์ในไฟล์เป็น publishable key ที่หน้าเว็บใช้อยู่แล้ว
- ตรวจแล้ว 5 พ.ย. 2569: build จากชุดนี้ได้ไฟล์ตรงกับ `ft-test/` (commit `b0ee029`) ทุกไบต์
